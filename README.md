# Sembang AI

**Notes, Experiments, and Practical Learning on AI, Large Language Models, and Local LLMs.**

Sembang AI is my personal knowledge repository for documenting experiments, technical notes, practical guides, and lessons learned while exploring Artificial Intelligence (AI) and Large Language Models (LLMs).

This repository serves as a long-term reference and backup for my AI-related learning and technical writing, alongside articles published on [DEV Community](https://dev.to/hardyweb).

The focus is on understanding how AI and LLM technologies work, experimenting with different tools and models, and documenting practical approaches that can be reproduced, evaluated, and improved over time.

## Disclaimer

This repository is a personal learning and documentation project. The experiments, configurations, and observations are shared for educational and informational purposes.

Results may vary depending on the hardware, software versions, model releases, and operating environment. Examples should be reviewed and tested before being used in production.
